# Qwen3-1.7B GRPO Results

This directory contains GRPO evaluation results for Qwen3-1.7B.

**These results are Pass@1 only. No GRPO Pass@16 results are included.**

The shard files are parallel evaluation partitions, not independent Pass@N samples.

Non-coding benchmarks: MATH-500, AIME25, OlympiadBench, MMLU-Pro, GPQA-Diamond.

Coding benchmark: LiveCodeBench v6 new-175, including raw and officially scored outputs.

Evaluated checkpoint: grpo_round8.
